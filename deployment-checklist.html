🎯 Deployment Steps

Step 1: Deploy Frontend to Netlify (5 min)

Easiest Method - Manual Deploy:

  1. Go to https://app.netlify.com
  2. Sign up or log in
  3. Click "Add new site" → "Deploy manually"
  4. Drag and drop the build folder
  5. Done! 🎉
Open Netlify Dashboard

Step 2: Deploy Backend to Render.com (10 min)

Free hosting for your Python backend:

  1. Go to https://render.com
  2. Create "New Web Service"
  3. Connect your GitHub repo or use Git URL
  4. Configure:
Root Directory: backend
Build Command: pip install -r requirements.txt
Start Command: uvicorn main:app --host 0.0.0.0 --port $PORT

Add environment variables (click Advanced):

GEMINI_API_KEY = [Your key from .env]
QDRANT_URL = [Your Qdrant URL from .env]
QDRANT_API_KEY = [Your Qdrant key from .env]
Open Render.com

Step 3: Connect Frontend to Backend (2 min)

Link your deployed services:

  1. Copy your Render backend URL (e.g., https://your-app.onrender.com)
  2. In Netlify: Site settings → Environment variables
  3. Add variable:
    Key: REACT_APP_API_URL
    Value: https://your-backend.onrender.com
  4. Trigger redeploy in Netlify
  5. Test your chatbot! 🎉
